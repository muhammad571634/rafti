# Nano Banana: character portraits, ready to copy

How to use (the same three steps for every character):

1. Open Gemini and start a **new chat** for each character (an old chat remembers the last person).
2. Attach **one** image: `assets/avatars/c_kai.png` from this repo (it shows the art style).
3. Copy the whole grey block under the character's name, paste it, send.

Save the result as `c_<id>.png` (for example `c_jun.png`) and send it in chat, or put it in
`assets/raw/avatars/`. Rowan is already done.

If a face looks too much like Kai, send the same prompt again in a new chat.
