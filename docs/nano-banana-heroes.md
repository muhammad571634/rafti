The Today card shows the character you talked with last (`docs/today-hero.md`). With a
wide scene it looks finished; without one the square portrait is cropped to fit. These
24 characters have a portrait but no scene yet.

For every character (same steps each time):

1. Open Gemini and start a **new chat** (an old chat remembers the last person).
2. Attach **two** images, in this order: the character's portrait `assets/avatars/c_<id>.png`,
   then `assets/heroes/c_sol.jpg` (the style and layout reference).
3. Copy the grey block under the character's name, paste it, send.

Save the result as `c_<id>.png` and put it in `assets/raw/heroes/` (or send it in chat).
The agent runs `python scripts/build-brand-art.py characters` and the card picks it up.

If the person in the result is Sol, or the café from Sol's picture is copied, send the
same prompt again in a new chat.
