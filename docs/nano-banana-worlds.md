# Nano Banana prompts: the 15 new Worlds 2.0 characters

Owner draws these in Gemini (Nano Banana). Style was found over four tries on Ronan (2026-10-30, HANDOFF 0z68 item 4):
a painted scene with one action, a face large in the frame, a relaxed brow and something in the eyes. Never an ID shot.

**How**
1. New Gemini chat for each character. Paste the scene prompt. Save it as `art-new/c_<name>.png` in the repo.
2. In the same chat, paste the avatar prompt below. Save it as `art-new/c_<name>_avatar.png`.
3. Tell Claude when a world is done. Claude crops, compresses and wires them in.

Each character costs 2 images. Ronan's scene is done, so 29 are left: 14 scenes and 15 avatars.

**Avatar prompt (the same for everyone)**
```
Using the same character from this image, make a square 1:1 avatar for a small round icon. Tight head-and-shoulders shot, face filling most of the frame, turned slightly to one side, never a straight-on ID photo. Keep exactly the same face, hair, clothes, expression, colours and painting style. Simple softly blurred background in the same colours, so the face reads at a very small size. No text, signature or logo.
```
