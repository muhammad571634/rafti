high-end cinematic 2.5D semi-realistic digital illustration with smooth luminous skin, warm subsurface scattering, realistic adult proportions, rich clothing fabric detail, warm-against-cool 35mm film lighting, creamy bokeh — **ZERO black ink outlines, ZERO 2D comic/cartoon lineart**.

## Step-by-Step Workflow (same for every story)
1. Open a **BRAND-NEW Gemini chat** for each story.
2. Attach **`art-new/c_clara.png`** strictly as the **visual style reference**.
3. Send the **3:4 Group Scene Prompt** → save as `art-new/<story_id>.jpg`.
4. **In the same chat (without closing it)**, send each **1:1 Member Avatar Prompt** one by one → save as `art-new/<story_id>_<member_id>_avatar.jpg`.
